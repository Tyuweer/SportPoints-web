## 🚀 Как запустить для защиты

1. Клонировать репо
2. `pip install -r requirements.txt`
3. `python manage.py migrate` (миграции уже готовы)
4. `python manage.py load_data` (опционально, уже в БД)
5. `python manage.py runserver`
6. Открыть http://localhost:8000

**Тестовые учетные данные:** admin/admin, coach1/coach1, athlete1/athlete1
