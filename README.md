# CSP - Система управления спортсменами

Django приложение для управления спортсменами, соревнованиями и результатами с полной системой аутентификации и авторизации.

## 🚀 Быстрый старт

### Требования
- Python 3.8+
- pip

### Установка

1. **Установить зависимости:**
```bash
pip install -r requirements.txt
```

2. **Применить миграции:**
```bash
python manage.py migrate
```

3. **Загрузить тестовые данные (опционально):**
```bash
python manage.py load_data
```

4. **Запустить development server:**
```bash
python manage.py runserver
```

Приложение доступно по адресу: http://127.0.0.1:8000/

## 🗄️ База данных

### Модели:
- **User** - Django встроенная модель пользователя
- **UserGroup** - Группы пользователей (viewer, athlete, coach, moderator, admin)
- **UserProfile** - Расширенный профиль пользователя
- **EmailConfirmation** - Подтверждение email токенами
- **ActivityLog** - Журнал активности пользователей
- **Athlete** - Информация о спортсменах
- **Competition** - Информация о соревнованиях
- **Distance** - Дистанции соревнований
- **Result** - Результаты спортсменов

### Данные по умолчанию (после load_data):
- 1000+ спортсменов
- 16 соревнований
- 48 дистанций
- 5000+ результатов
- 5 пользователей
- 5 групп пользователей

## ⚙️ Конфигурация

### settings.py:
- DATABASE: SQLite (разработка) / PostgreSQL (production)
- CACHE: LocMem (разработка) / Redis (production)
- EMAIL: Console backend (разработка) / SMTP (production)
- ALLOWED_HOSTS: localhost, 127.0.0.1

### Для переключения на PostgreSQL:
Раскомментировать в settings.py:
```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'csp_db',
        'USER': 'postgres',
        'PASSWORD': 'password',
        'HOST': 'localhost',
        'PORT': '5432',
    }
}
```
